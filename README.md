# Kazbegi weekend · 13–14 November 2026

Статический одностраничный мини-сайт для поездки Тбилиси → Степацминда → Тбилиси.

## Особенности

- Адаптивный интерфейс для телефона
- Маршрут по пятнице и субботе, ориентировочное время остановок
- Навигация по точкам через Google Maps
- Напоминания о коротком световом дне и состоянии дорог

## Публикация

**Cloudflare Pages:** Workers & Pages → Create → Pages → Connect to Git → `Eastclap/kazbegi-weekend`. Framework: None; build command пустая; output directory: `/`.

**GitHub Pages:** Settings → Pages → Deploy from branch → `main`, directory `/ (root)`.

Откройте `index.html` локально для просмотра, никакая сборка не нужна.

## Примечание

Время и доступность точек зависят от дороги и погоды. Перед выездом проверьте https://georoad.gov.ge/en. Фотографии Unsplash — иллюстративные, не гарантируют точное соответствие местам.
